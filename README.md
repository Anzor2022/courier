# Курьер-mahnet — Android-приложение

Приложение курьера для сайта **mahnet.ru**. Внутри — окно с сайтом `https://mahnet.ru/courier/`
(та же логика, те же логины и пароли) и **родной сканер штрихкодов** (камера + Google ML Kit).
Экран не гаснет, тема всегда светлая, масштаб жестами не меняется. Маршрут к клиенту показывается
на карте Яндекса прямо внутри приложения (при первом нажатии разрешите определение местоположения).

## Как собрать APK на GitHub (без Android Studio)

1. Зайдите на https://github.com и создайте новый репозиторий (можно приватный), например `market-courier`.
2. Распакуйте этот архив и загрузите **все файлы проекта** в репозиторий
   (кнопка *Add file → Upload files*; папку `.github` тоже — это важно, в ней сборка).
   Если GitHub не показывает папку `.github` при выборе файлов, перетащите папку целиком мышкой.
3. Откройте вкладку **Actions**. Сборка *Build Android APK* запустится сама после загрузки файлов.
   Если нет — выберите её слева и нажмите **Run workflow**.
4. Через 3–6 минут сборка станет зелёной. Откройте её и внизу, в разделе **Artifacts**,
   скачайте `courier-apk` (zip с файлом `app-debug.apk`).
5. Скопируйте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку
   из этого источника — разрешите. При первом запуске разрешите доступ к камере.

Если сборка покажет красный крестик — откройте её, скопируйте текст ошибки из шага *Build debug APK*
и пришлите мне, я поправлю.

## Что внутри
- `app/src/main/java/ru/mahnet/courier/MainActivity.kt` — вся логика (окно сайта, сканер, подтверждения).
- `START_URL` в начале этого файла — адрес приложения курьера. Поменяйте, если сайт переедет.
- `.github/workflows/build.yml` — автоматическая сборка на GitHub.

## Как это работает со сканером
Сайт определяет, что он открыт внутри приложения (`window.AndroidApp`), и вместо сканера браузера
включает родную камеру. Приём всех посылок подряд и выдача товаров клиента работают без повторного
открытия камеры, а перед выдачей приложение спрашивает «Уверены?».

## Подпись и Google Play (по желанию)
Собирается отладочный APK (`app-debug.apk`) — он устанавливается на телефоны напрямую.
Для публикации в Google Play нужна подписанная сборка (release) со своим ключом: скажите, подготовлю.

## Версии и обновление поверх старого приложения
- Версия приложения: **1.0.N**, где N — номер сборки на GitHub. Первая сборка — 1.0.1, следующая — 1.0.2 и так далее.
- Все сборки подписаны одним и тем же ключом (`app/market-release.p12`), поэтому новый APK **устанавливается поверх уже
  установленного** приложения как обновление, данные и вход сохраняются.
- **Не удаляйте файл `app/market-release.p12` и не меняйте его.** Если ключ поменять, Android перестанет обновлять приложение поверх —
  придётся удалить старое и поставить заново. Репозиторий лучше держать приватным.
- Идентификатор приложения — `ru.mahnet.courier`, ключ подписи создан заново. Если на телефоне стоит приложение, собранное раньше, удалите его один раз и поставьте первую сборку из этого проекта; следующие будут ставиться поверх.
